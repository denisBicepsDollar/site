# features/goods — страница товара

Модуль страницы редактирования товара (`/dashboard/goods/:id`).

Раньше это был один файл `GoodPage.jsx` на 750+ строк: состояние, загрузка фото,
подтверждения и вся разметка вперемешку. Теперь он разбит по слоям.

## Структура

```
goods/
├── GoodPage.jsx              # страница: данные из хука + раскладка секций + confirm-ы
├── constants.js              # моки товара, категории, статусы, размеры, лимиты полей
│
├── model/                    # логика без разметки
│   ├── formState.js          # чистое состояние формы и операции над ним (варианты, фото)
│   ├── snapshot.js           # слепок формы → «есть ли несохранённые изменения»
│   ├── photos.js             # плоский список всех фото для лайтбокса
│   └── useGoodForm.js        # хук формы: useState + действия + загрузка файлов + save
│
├── components/               # секции страницы (по одной на блок интерфейса)
│   ├── GoodHeader.jsx        # прилипающая шапка: «К товарам», статус изменений, «Сохранить»
│   ├── GeneralInfoSection.jsx# название + мета: артикул, обновлён, вариантов, категория, цена
│   ├── DescriptionSection.jsx# описание
│   ├── PhotosSection.jsx     # фото по вариантам + колонка текущей обложки
│   ├── CoverPanel.jsx        # правая колонка: текущая обложка товара
│   ├── VariantsSection.jsx   # быстрые кнопки размеров + таблица вариантов
│   ├── VariantRow.jsx        # строка варианта: размер, остаток, цена, фото, удаление
│   ├── StatusSection.jsx     # радио-статусы
│   ├── NotesSection.jsx      # сворачиваемые заметки
│   └── PhotoViewer.jsx       # полноэкранный просмотр фото
│
└── ui/                       # мелкие переиспользуемые элементы
    ├── PhotoTile.jsx         # превью фото с кнопками «удалить»/«сделать обложкой»
    ├── UploadTile.jsx        # плитка «+ Фото»
    ├── PriceInput.jsx        # цена с ₽ (базовая и цена варианта)
    ├── StockStepper.jsx      # остаток [−][число][+]
    ├── CategorySelect.jsx    # выпадающий список категорий
    ├── CharCounter.jsx       # «12 / 100»
    └── Meta.jsx              # «Артикул: PL-002», бейдж, разделитель
```

## Правила, по которым стоит развивать дальше

1. **Данные — только через `useGoodForm`.** Секции не знают про `useState`
   формы: им передают значение и колбэк (`value` / `onValueChange`).
2. **Состояние, которое нужно только блоку, живёт в блоке** — открыт ли список
   категорий, развёрнуты ли заметки, какой фото открыт в лайтбоксе.
3. **`window.confirm` и прочие «связи с миром» — в `GoodPage.jsx`**, чтобы
   секции и `ui` оставались простыми и предсказуемыми.
4. **Функции из `model/` не зависят от React** — их легко покрыть тестами.
5. **Когда появится API** — меняется `findGoodById` в `constants.js` и `save`
   в `useGoodForm`; остальной код страницы не трогаем.

## Что осталось за кадром (можно доработать отдельно)

- `save` пока только сбрасывает «изменённые» — нужен вызов API.
- Кнопка «Удалить товар» ничего не делает.
- `photo.variantIndex === null` — общее фото товара; для фото без варианта
  кнопки «сделать обложкой варианта» нет (так и задумано).
