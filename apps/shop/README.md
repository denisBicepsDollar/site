# Магазин (apps/shop) — легаси

Старая витрина на чистом HTML/CSS/JS (без сборки). В проде раздаётся nginx из `/var/www/shop`.

Локально просто открой `index.html` или подними любой статический сервер из каталога `apps/shop`.

Единственная команда:

```bash
npm run lint   # eslint (JS/JSON/CSS)
```

Актуальная витрина — `apps/web` (Next.js), этот каталог поддерживается только как фолбэк.
